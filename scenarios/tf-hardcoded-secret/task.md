# database password is committed in plain text

`main.tf` stores the `orders` database credentials in Secrets Manager, but the
password is a literal in the code, so it is in git history and in every
reviewer's checkout. The old value is considered leaked.

Change the Terraform so that:
- the password is generated by Terraform (`random_password`, at least 24
  characters) and never appears in any file in this directory;
- the secret keeps its JSON shape: `{"username": "orders", "password": ...}`;
- the old password string does not appear anywhere in this directory.

The verifier scans the directory, applies against LocalStack from fresh state
and evaluates policy over `terraform show -json`.
